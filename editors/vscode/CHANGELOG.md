# Changelog

## 0.1.0 - 2026-11-06

- Package syntax highlighting, ten snippets, Run (F5), and Compile commands.
- Wait for saves and launch process tasks with literal paths and source-relative I/O.
- Resolve settings per workspace folder and detect or configure the compiler runtime.
- Support highlighting and snippets in Restricted Mode; require trust for execution.
- Test the installed VSIX against actual interpreter and compiler binaries.
