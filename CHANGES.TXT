GW-BASIC 2026 -- Change History
================================

Unreleased
  - Preserve INPUT ; and LINE INPUT ; editing positions in file-launched and
    native POSIX terminal runs. Restore terminal settings after input, Ctrl-C
    and EOF; keep piped and file input on their stdio path. Compile POS arguments
    correctly, including their evaluation side effects. Handle printed tabs,
    complete modified CSI keys and queued interpreter INPUT$ bytes. Empty INPUT
    strings avoid zero-length copies through NULL pointers.
  - Match WHILE/WEND trapped-error retry behavior, nested loop identity and
    GOSUB boundaries. WEND condition errors report WHILE's line but retry WEND
    after removing its frame; RESUME NEXT continues after WEND. Reuse the saved
    match during WEND evaluation and reject malformed WEND tails in native code.
  - Use the original 24-bit RND sequence and initial state; honor zero and
    negative arguments in native code as well as the interpreter. Match explicit
    RANDOMIZE seed conversion and state updates; recapture older seeded tests
    from the original executable. Preserve checked division operand order and
    repeat RND state when a negative argument underflows to zero.
  - Expand the corpus to 32 cases from seventeen listings, including random
    Hi-Lo, Bagels and Craps games, Awari/Checkers checkpoints and their original
    FOR without NEXT failures. Vendored listings remain unchanged.
  - Execute DOS16 and DOS32 runtime smoke tests in CI using a checksum-pinned
    FreeDOS boot image and disposable QEMU disks, without root or KVM.
    Check saved output, editor input/cursor behavior and compute-loop breaks;
    missing prerequisites, timeouts and mismatches fail the job.
  - Accept ASCII line labels from 0 through 65529 in the editor, loader and
    compiler. Preserve high branch targets, ERL, and RENUM/SAVE round trips
    without changing signed expression integer limits. Keep EDIT's active
    command buffer intact when storing the edited line.
    Return to direct mode after interpreter RENUM and relocate saved function
    and DATA pointers. Keep expanded token records intact in binary SAVE/LOAD.
  - Reuse the statement dispatcher frame for inline IF branches to avoid
    exhausting the 16-bit DOS stack during nested error recovery.
  - Resume native error handling at source statement boundaries, including
    same-line continuations, retries, RESUME 0, and IF/ELSE entry points.
    Clear ERR on RESUME and preserve handler protection for invalid targets.
  - Keep the interactive INPUT ; and LINE INPUT ; editing cursor on Enter,
    synchronize PRINT positioning, and retain the complete answer string.
  - Add 20 native error-recovery references and 16 original-console input cases.
  - Validate FOR headers and lexical NEXT names/types before assigning the
    counter; preserve header evaluation errors and BASIC error line numbers.
  - Keep FOR loops inside their GOSUB frame, preserving caller loops and
    discarding unfinished subroutine loops on RETURN.
  - Execute conditional and later DEFTYPE declarations through the interpreter
    runtime in compiled executables. Entry-prefix declarations still compile
    natively; runtime DEFTYPE with $EXTERN produces an explicit diagnostic.
  - Preserve caller loop scope after an undefined GOSUB; retry the failing
    statement in the interpreter for RESUME and skip RESUME NEXT token payloads.
  - Reject spaces inside variable names or before their type suffixes.
  - Delegate compiled OUT, WAIT and MOTOR statements to the device runtime;
    do not interpret encoded port operands as separate statements.
  - Disable 16-bit linker far-call rewriting after reproducible FreeDOS faults.
  - Match GW-BASIC integer rounding and range checks, including FOR bounds.
  - Reset the print column after INPUT/LINE INPUT when Enter starts a new line.
  - Expand independent gameplay references from 13 cases/eight listings to
    23 cases/twelve listings, including Tic-Tac-Toe, Towers, Chomp and One Check.
  - Add 54 Microsoft GW-BASIC semantic references; correct four earlier
    permissive FOR expectations against the original executable.

v0.18.1
  - Fix numbered-line Ok prompts, INPUT prompt boundaries, AUTO, and input editing.
  - Preserve ASCII LOAD command buffers; keep output and the cursor visible
    when terminals shrink; retain F-key labels after CLS.
  - Reduce the 16-bit DOS string-pool default to 8 KiB so program lines can be stored.
  - Reject token-buffer overflow without truncating or running the partial line.
  - Bound CLEAR token skips and keep shortened input safe on very small screens.
  - Poll DOS break keys so Ctrl-C interrupts loops without keyboard input.
  - Align LOCATE and the DOS hardware cursor with BASIC's one-based coordinates.
  - Correct parenthesized strings, shared array storage, DEF FN token scanning,
    INPUT scalar preservation, and backward TAB behavior in compiled programs.
  - Track active FOR loops at runtime so alternate and shared NEXT statements
    work; retain all GOSUB return targets and clear both control stacks at CLEAR.
  - Skip initially empty FOR loops in the interpreter and compiler.
  - Preserve numeric and nested IF/ELSE branches; raise BASIC errors for missing
    ELSE targets instead of falling through or generating undefined C labels.
  - Add fixed-input Microsoft GW-BASIC reference comparisons and an explicit
    build audit for 98 BASIC Computer Games listings.
  - Fail test suites on mismatches, process errors, missing outputs, and timeouts.
  - Prepare Linux and DOS release archives with source provenance and checksums.

v0.18.0
  - Cross-language linking: link compiled BASIC objects into a C/Fortran
    project (--emit-obj, --main-name), and call C functions from BASIC via
    the '$EXTERN NAME(ARGS) AS TYPE pragma (Levels 1 and 2)
  - Codegen fix: parenthesized string comparison
  - Performance flags: --no-gc-check (skip per-line GC/Ctrl-Break check),
    --fast-math (skip division-by-zero guard)
  - Larger 32-bit/Linux static caps (1024 vars, 256 arrays, 64 FOR, 128
    GOSUB, 64 WHILE); 16-bit real-mode DOS keeps the original caps
  - DATE$/TIME$ assignment shifts a process-local clock offset

v0.17.0
  - Compiler memory safety: --warn (static analysis), --safe (checked
    integer arithmetic, enhanced array/GOSUB diagnostics), --safe=sanitize
  - 16-bit real-mode DOS target (Makefile.dos16): 128KB standalone MZ
    executable, no DOS extender required, far-heap TUI screen buffer
  - 32-bit DOS/4GW target (Makefile.dos): 175KB LE executable
  - Tested on FreeDOS 1.4

v0.16.0

  - Cross-compile to DOS with OpenWatcom (24/24 files)
